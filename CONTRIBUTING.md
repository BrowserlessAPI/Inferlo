# Contributing to Inferlo

Thanks for helping. Inferlo's goal is to be the TypeScript backend framework that AI models (and people) write correct code with on the first try, so every change is judged by that.

1. Read [AGENTS.md](AGENTS.md): it lists the design rules and the checks.
2. Open an issue first for new features, so we can agree on the API before you build it.
3. Keep pull requests small, with tests and docs.
4. Run all checks from AGENTS.md before pushing.

Bug reports: include the Inferlo version, runtime (Node/Bun/Deno and version), a minimal reproduction and the full error output, including its KR code.
